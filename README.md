# 网搜

一个收录官方、正版与免费优先动漫观看入口的中文导航站。

## 功能

- 关键词搜索平台、类型、字幕与地区信息
- 按官方频道、中文平台、免费点播、新番等分类筛选
- 清楚标注免费方式、字幕和常见地区限制
- 响应式布局、键盘搜索快捷键与无结果状态

## 收录原则

本站仅指向官方、正版或明确获得授权的内容源，不提供盗版下载、网盘搬运或绕过付费限制的方法。内容可用性、字幕、广告和地区限制以各平台实时页面为准。

## 开发

```bash
pnpm install
pnpm dev
pnpm build
```

## 基础项目与许可

本项目基于 [fastdemo/aeri](https://github.com/fastdemo/aeri) 改造，参考其电影感首页、搜索、分类和响应式交互结构。选用的上游版本最近提交于 2026-09-19，检索日期为 2026-09-22。

保留 React 19、TypeScript、Vite 和 Tailwind CSS 技术栈，移除了视频源解析、播放、账号追踪和后端代理，重构为只跳转到正版来源的静态目录。
