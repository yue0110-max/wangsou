# 网搜

一个展示实时热门动漫、支持按作品名称搜索的中文动漫发现站。

## 功能

- 首页通过 AniList API 实时展示当前最热的 10 部动漫
- 支持使用中文、日文或英文动漫名称搜索更多作品
- 展示封面、评分、人气、年份、集数、状态、类型与剧情简介
- 响应式布局、键盘搜索快捷键、加载骨架与异常状态

## 收录原则

本站只展示动漫资料与趋势，不在首页推荐第三方网站，也不提供盗版播放、下载、网盘搬运或绕过付费限制的方法。动漫资料由 AniList GraphQL API 提供。

## 开发

```bash
pnpm install
pnpm dev
pnpm build
```

## 基础项目与许可

本项目基于 [fastdemo/aeri](https://github.com/fastdemo/aeri) 改造，参考其电影感首页、搜索、分类和响应式交互结构。选用的上游版本最近提交于 2026-09-19，检索日期为 2026-09-22。

保留 React 19、TypeScript、Vite 和 Tailwind CSS 技术栈，移除了视频源解析、播放、账号追踪和后端代理，重构为热门榜与标题搜索界面。
