# 网搜

一个展示实时热门动漫、支持按作品名称搜索并查找在线播放来源的中文动漫发现站。

## 功能

- 首页通过 AniList API 实时展示当前最热的 10 部动漫
- 支持使用中文、日文或英文动漫名称搜索更多作品
- 点击动漫可在内嵌的樱花动漫页面搜索、选择作品与剧集，也可切换到 AniList 标注的正版剧集与流媒体平台
- 搜索结果为空时仍可使用原关键词打开樱花动漫搜索
- 对可嵌入的 YouTube 正版片段提供站内播放器
- 展示封面、评分、人气、年份、集数、状态、类型与剧情简介
- 响应式布局、键盘搜索快捷键、加载骨架与异常状态

## 收录原则

动漫资料和正版平台信息由 AniList GraphQL API 提供。用户指定的 `v.yhhua.com.cn` 当前通过全屏框架展示 `yinghuadongman.org.cn`，因此樱花动漫入口使用后者的公开搜索页。该第三方页面及播放由来源网站提供，网搜不验证其授权、免费情况或可用地区，也不抓取、解析、代理或存储视频流。

## 开发

```bash
pnpm install
pnpm dev
pnpm build
```

## 基础项目与许可

本项目基于 [fastdemo/aeri](https://github.com/fastdemo/aeri) 改造，参考其电影感首页、搜索、分类和响应式交互结构。选用的上游版本最近提交于 2026-09-19，检索日期为 2026-09-22。

保留 React 19、TypeScript、Vite 和 Tailwind CSS 技术栈；动漫目录和搜索使用 AniList，播放详情内嵌樱花动漫搜索页并提供 AniList 标注的正版剧集入口，在平台允许时嵌入 YouTube 播放器。
